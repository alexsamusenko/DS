# Model Card: <название модели>

По образцу Model Cards for Model Reporting (Mitchell et al., 2019) — см. `docs/governance/best_practices.md`.

## Назначение
Какую задачу решает, в каком модуле используется (L1/L4/...).

## Архитектура и базовая модель
Тип модели, базовые веса (если дообучение), версия.

## Данные обучения
Источник, объём, лицензия (ссылка на запись в `docs/governance/licenses.md`), реальные/синтетические.

## Гиперпараметры
Ссылка на `docs/chapter2/model_training.md` или таблица здесь, если модель не описана там.

## Метрики
Метрика, значение, на каких данных измерено (train/val/test), дата измерения.

## Известные ограничения
Что модель не умеет, на каких данных не проверена, для какого масштаба не валидна.

## Дата и статус
Когда обучена, кем, актуальна ли (или заменена более новой версией).
