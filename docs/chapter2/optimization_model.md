# 2.4. Алгоритм поддержки принятия решений для дифференцированного внесения удобрений

> Черновик раздела главы 2 диссертации. Соответствует задаче 5 и положению 4, выносимому на защиту. Реализует уровень L5 архитектуры (см. артефакт «Архитектура DS», §2.3.6).

## 2.4.1. Постановка задачи

Поле разбивается на элементарные участки `{p_1, …, p_K}` (зоны дифференцированного управления, ячейки картограммы) площадью `a_k`. Для каждого участка требуется выбрать дозу удобрения `d_k ∈ [d_min, d_max]`, максимизирующую суммарную экономическую эффективность по полю:

```
max_{d_1,…,d_K}  Σ_k a_k · Profit_k(d_k)
```

где `Profit_k(d) = p_Y · Ŷ_k(d) − p_D · d` — прибыль с единицы площади участка `k` при дозе `d`, `p_Y` — цена продукции, `p_D` — цена удобрения, `Ŷ_k(d)` — функция отклика урожайности на дозу для участка `k` (§2.4.2).

В отличие от нормативных подходов (§1.3.3), назначающих единую дозу на всё поле, здесь доза оптимизируется **индивидуально для каждого участка** с учётом внутрипольной неоднородности — прямая реализация научной новизны п. 3 введения.

## 2.4.2. Кривая отклика урожайности на дозу: интеграция с моделью L4

Функция отклика строится в два слоя, связывая прогнозную модель (L4, §2.3) с задачей оптимизации:

```
Ŷ_k(d) = Ŷ_k^base + R_k · (1 − e^{−d / s_k})
```

где:

- `Ŷ_k^base` — базовый потенциал урожайности участка **без дополнительного внесения**, получаемый из мультимодальной модели L4 (`F(x_k)`, §2.3.3) по текущим наблюдаемым признакам участка (почвенные, спектральные, история);
- второе слагаемое — агрономическая кривая отклика на дозу (модель Митчерлиха — классический в агрономии закон убывающей отдачи), где `R_k` — предельный дополнительный урожай при неограниченной дозе (тем выше, чем больше выявленный дефицит элемента питания на участке — неоднородность поля), `s_k` — масштаб насыщения.

Такая конструкция — не альтернатива модели L4, а её продолжение: L5 использует прогноз L4 как точку отсчёта и добавляет к нему объясняемую агрономическую зависимость от управляемого фактора (дозы), которого нет в ретроспективных признаках L4 напрямую в виде переменной решения.

## 2.4.3. Оптимизация без ограничения бюджета

`Profit_k(d)` вогнута по `d` (сумма вогнутой `Ŷ_k(d)` и линейной по `d` функции), поэтому оптимум находится из условия первого порядка:

```
∂Profit_k/∂d = p_Y · (R_k/s_k) · e^{−d/s_k} − p_D = 0
⟹ d_k* = −s_k · ln( p_D · s_k / (p_Y · R_k) ),   ограниченное [d_min, d_max]
```

Если выражение под логарифмом `≥ 1` (предельная выгода при `d=0` уже не покрывает стоимость удобрения), `d_k* = d_min` — внесение на этом участке нерентабельно. Задача по построению **сепарабельна по участкам** (нет взаимодействия между `d_k` разных участков), поэтому глобальный оптимум — это независимый оптимум по каждому участку, что соответствует ветвям диаграммы §2.3.6 («для каждого участка i»).

## 2.4.4. Оптимизация при ограничении бюджета

При ограничении `Σ_k a_k · d_k ≤ B` (суммарный бюджет удобрений) задача решается методом множителей Лагранжа:

```
d_k(λ) = clip( −s_k · ln( (p_D + λ·a_k) · s_k / (p_Y · R_k) ),  d_min, d_max )
```

где `λ ≥ 0` подбирается бисекцией так, чтобы `Σ_k a_k · d_k(λ) = B` (если суммарный расход при `λ=0` уже не превышает `B`, ограничение не связывающее, `λ=0`). Экономический смысл `λ` — теневая цена бюджета: решение уравнивает предельную отдачу удобрения на разных участках с поправкой на их площадь, а не распределяет дозу поровну.

## 2.4.5. Критерий эффективности: дифференцированное внесение против равномерного

Пусть `B` — фиксированный суммарный расход удобрения (одинаковый в обоих сценариях, чтобы сравнение было корректным). Сравниваются:

- **дифференцированный сценарий** — решение §2.4.4 при бюджете `B`;
- **нормативный (равномерный) сценарий** — одна и та же доза `d_uniform = B / Σ_k a_k` на всех участках.

Поскольку равномерное распределение — частный случай допустимых распределений при том же суммарном расходе `B`, а решение §2.4.4 максимизирует прибыль по всем таким распределениям, **по построению**:

```
Profit_differentiated(B) ≥ Profit_uniform(B)
```

— это не эмпирическое наблюдение (как в §2.2.6, §2.3.6), а формальное следствие оптимальности решения задачи с ограничением, и именно оно проверяется в `tests/test_optimization.py::test_differentiated_beats_uniform_at_same_budget` как тест корректности реализации оптимизатора, а не как статистическая гипотеза.

## 2.4.6. Карта-задание и экономический эффект

Результат оптимизации — вектор `{d_k*}` — оформляется в карту-задание (соответствие «участок → доза») для экспорта на технику (см. диаграмму §2.3.6, блок «Карта-задание») и сопровождается количественной оценкой эффекта:

```
ΔProfit = Profit_differentiated(B) − Profit_uniform(B)
ΔУдобрения = (d_uniform − d_k*) — экономия/перерасход по каждому участку при равном суммарном расходе
```

что напрямую реализует пункты практической значимости работы (введение: «сократить потери от необоснованных решений», «обеспечить экономию ресурсов»).

## 2.4.7. Связь с реализацией

## 2.4.8. Обобщение на несколько видов удобрений (N/P/K)

§2.4.2–2.4.7 рассматривают дозу как скаляр — одно обобщённое «удобрение». На практике вносятся несколько видов одновременно (азотные, фосфорные, калийные), и они не взаимозаменяемы: избыток азота не компенсирует нехватку фосфора. Это — закон минимума (Либих), а не аддитивность, и его нужно отразить в самой форме функции отклика, а не только в ограничениях.

Обобщение — многокомпонентный закон Митчерлиха-Бауле (мультипликативная форма):

```
Y_k(d_1,…,d_J) = Ŷ_k^base + R_k · Π_{j=1}^{J} (1 − e^{−d_j / s_{k,j}})
```

где `J` — число видов удобрений (в прототипе `J=3`: N, P, K), `d_j` — доза `j`-го вида, `s_{k,j}` — масштаб насыщения по этому виду на участке `k`. Ключевое отличие от аддитивной суммы `Σ_j R_j(1-e^{-d_j/s_j})`: если хотя бы один множитель близок к 0 (соответствующий элемент питания сильно дефицитен), всё произведение близко к 0 — прибавка урожая ограничена самым дефицитным фактором, а не усредняется по всем сразу, что и требует агрономический закон минимума.

Прибыль обобщается прямо: `Profit_k(d) = p_Y·Y_k(d) − Σ_j p_j·d_j`, где `p_j` — цена `j`-го вида удобрения.

**Отличие от §2.4.3 по разрешимости.** При `J=1` `Profit_k(d)` вогнута, и оптимум находится аналитически из условия первого порядка (§2.4.3). При `J>1` произведение вогнутых по каждому `d_j` множителей не обязано быть совместно вогнутым по вектору `d` — аналитического решения в общем виде нет. Оптимум по каждому участку (без бюджета, задача остаётся сепарабельной по участкам, но не по видам удобрений внутри участка) находится численно (L-BFGS-B с ограничениями `[d_min, d_max]^J`) — глобальная оптимальность найденной точки для `J>1` не доказывается аналитически, в отличие от `J=1`, и это явно отмечено как отличие в строгости результата, а не скрыто.

Бюджетное ограничение для `J>1` (общий бюджет на все виды удобрений сразу, метод Лагранжа с одним множителем на вид удобрения) в прототипе **не реализовано** — открытый пункт для дальнейшей работы, отмечено, а не молча пропущено.

## Выводы

Раздел 2.4 формализует переход от прогноза (L4) к управленческому решению (L5): кривая отклика на дозу строится как продолжение модели L4 агрономическим законом убывающей отдачи, оптимизация участков сепарабельна и решается аналитически без бюджета и методом Лагранжа с бюджетом, а превосходство дифференцированного внесения над нормативным равномерным при одинаковом суммарном расходе удобрений доказуемо по построению, а не проверяется эмпирически. §2.4.8 обобщает однокомпонентную модель на несколько видов удобрений через мультипликативный закон Митчерлиха-Бауле, отражающий закон минимума Либиха — ценой перехода от аналитического к численному решению при `J>1`.
