# 2.2. Комбинированный алгоритм предобработки пространственно-временных агрономических данных

> Черновик раздела главы 2 диссертации. Соответствует задаче 3 и положению 2, выносимому на защиту. Реализует уровень L3 архитектуры (см. артефакт «Архитектура DS», §2.3.5).

## 2.2.1. Постановка задачи

Пусть агрономический показатель (влажность почвы, температура, спектральный индекс) измеряется в конечном множестве пространственных точек `{s_1, …, s_M}` (сенсоры, узлы регулярной сетки поля) на конечном множестве моментов времени `{t_1, …, t_T}`. Данные образуют матрицу

```
X ∈ R^{M×T}
```

в которой подмножество ячеек `Ω ⊆ {1..M}×{1..T}` наблюдается, а дополнение `Ω^c` пропущено и подлежит восстановлению. Требуется построить оценку `X̂_{m,t}` для всех `(m,t) ∈ Ω^c`, минимизирующую ошибку относительно истинных (неизвестных на практике) значений.

Как показано в §1.2.2, агрономические показатели одновременно демонстрируют **пространственную автокорреляцию** (первый закон географии Тоблера, §1.2.2) и **временную зависимость** (фенологическая динамика, накопительные эффекты). Метод восстановления, использующий только одну из этих двух структур, систематически теряет часть сигнала — что количественно подтверждено в работе Ли и др. (2021, §1.2.2): модель, учитывающая только пространственную или только временную вариацию, уступает по RMSE модели, учитывающей обе. Отсюда требование к алгоритму — **комбинировать оба источника информации**, а не выбирать один из них.

## 2.2.2. Детекция аномалий

Перед восстановлением пропусков из ряда каждой точки `s_m` удаляются выбросы — значения, вероятно являющиеся ошибками измерения (разрядка сенсора, помехи передачи), а не пропусками. Используется модифицированная z-оценка на основе медианного абсолютного отклонения (MAD), устойчивая к самим выбросам:

```
MAD_m = median(|X_{m,t} - median_t(X_{m,·})|)
mz_{m,t} = 0.6745 · (X_{m,t} - median_t(X_{m,·})) / MAD_m
```

Значение помечается как аномалия и переводится в разряд пропущенных, если `|mz_{m,t}| > k` (по умолчанию `k = 3.5`, стандартный порог для модифицированной z-оценки). Это соответствует блоку «Детекция аномалий» на диаграмме §2.3.5 архитектурного документа.

## 2.2.3. Пространственная оценка (кригинг)

Для момента времени `t` с наблюдаемым подмножеством точек `M_t^obs ⊆ {1..M}` строится вариограмма `γ(h)` и обыкновенный кригинг-предиктор:

```
X̂^spatial_{m,t} = Σ_{i ∈ M_t^obs} λ_i · X_{i,t},   Σ λ_i = 1
```

где веса `λ_i` минимизируют дисперсию оценки при условии несмещённости, стандартным образом определяемым через вариограмму. Кригинг также даёт **дисперсию оценки** `σ²_spatial(m,t)` — величину, используемую ниже как мера доверия к пространственной оценке. Оценка недоступна (`σ²_spatial = ∞`), если `|M_t^obs| < 3` (недостаточно точек для оценки вариограммы) — что соответствует ветви «нет соседей» на диаграмме §2.3.5.

## 2.2.4. Временная оценка (тренд)

Для точки `s_m` с наблюдаемым подмножеством моментов `T_m^obs ⊆ {1..T}` строится локальная сглаживающая модель `f_m(t)` (в прототипе — полином низкой степени, для реальных данных — сезонно-трендовое разложение), и:

```
X̂^temporal_{m,t} = f_m(t)
σ²_temporal(m,t) = (1/|T_m^obs|) · Σ_{τ ∈ T_m^obs} (X_{m,τ} - f_m(τ))²
```

то есть дисперсией служит остаточная ошибка подгонки модели на наблюдаемых точках того же `m`. Оценка недоступна, если `|T_m^obs| < 2`.

## 2.2.5. Комбинирование оценок

Обе оценки — независимые (используют ортогональные измерения: одна — срез по пространству при фиксированном `t`, другая — срез по времени при фиксированном `m`). Для независимых несмещённых оценок с известными дисперсиями минимальную дисперсию комбинации даёт **взвешивание по обратной дисперсии** (inverse-variance weighting):

```
X̂_{m,t} = (w_spatial · X̂^spatial_{m,t} + w_temporal · X̂^temporal_{m,t}) / (w_spatial + w_temporal)

w_spatial = 1 / σ²_spatial(m,t),   w_temporal = 1 / σ²_temporal(m,t)
```

Вырожденные случаи, соответствующие ветвям диаграммы §2.3.5:

- доступна только пространственная оценка → `X̂_{m,t} = X̂^spatial_{m,t}`;
- доступна только временная оценка → `X̂_{m,t} = X̂^temporal_{m,t}`;
- недоступна ни одна → ячейка помечается как невосстановимая (флаг качества, а не догадка).

## 2.2.6. Критерии оценки качества восстановления

Качество алгоритма проверяется методом маскирования: часть **известных** значений искусственно скрывается, восстанавливается алгоритмом и сравнивается с истинными:

```
RMSE = sqrt( (1/|Ω_test|) Σ_{(m,t)∈Ω_test} (X̂_{m,t} - X_{m,t})² )
MAE  = (1/|Ω_test|) Σ_{(m,t)∈Ω_test} |X̂_{m,t} - X_{m,t}|
```

Требование к комбинированному алгоритму: `RMSE_combined ≤ min(RMSE_spatial_only, RMSE_temporal_only)` на тестовой маске — то есть комбинирование не должно ухудшать результат по сравнению с использованием одного источника, и в общем случае обязано его улучшать за счёт использования дополнительной информации. Этот критерий проверяется в прототипе (`tests/test_preprocessing.py::test_combined_beats_either_alone`) на контролируемых данных с известной пространственно-временной структурой, воспроизводящей качественный результат Ли и др. (2021, §1.2.2): STVC-модель (10.64 бушеля/акр, R²=0.81) превосходит модели с одной лишь временной (15.68, R²=0.56) или одной лишь пространственной (16.48, R²=0.64) вариацией.

## 2.2.7. Связь с реализацией

Алгоритм реализован в `src/ds_preprocessing/`: `anomaly.py` (§2.2.2), `spatial.py` — обыкновенный кригинг через библиотеку `pykrige` (§2.2.3), `temporal.py` — локальная полиномиальная аппроксимация (§2.2.4), `combine.py` — взвешивание по обратной дисперсии (§2.2.5), `metrics.py` — RMSE/MAE (§2.2.6). Валидация — на контролируемом синтетическом наборе (`synthetic.py`) с известной пространственно-временной структурой и искусственно скрытыми значениями, поскольку прямая проверка ошибки восстановления по определению требует эталона, недоступного в реальных пропущенных данных; апробация на открытых источниках из `docs/datasets.md` (без известного эталона, но на реальных полях) — задача главы 4.

## Выводы

Раздел 2.2 формализует комбинированный алгоритм восстановления пропусков как взвешивание по обратной дисперсии двух независимых оценок — пространственной (кригинг) и временной (локальный тренд), с явным вырождением в один источник при отсутствии другого и явным флагом невосстановимости, когда недоступны оба. Это отличает предложенный подход от чисто геостатистических методов (§1.3.1), учитывающих только пространственную структуру, и от классических методов временных рядов, игнорирующих пространственную корреляцию.
