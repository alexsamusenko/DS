# 2.3. Мультимодальная модель прогнозирования урожайности сельскохозяйственных культур

> Черновик раздела главы 2 диссертации. Соответствует задаче 4 и положению 3, выносимому на защиту. Реализует уровень L4 архитектуры (см. артефакт «Архитектура DS», §2.3.1, §2.3.4).

## 2.3.1. Постановка задачи

Пусть для пары «поле — сезон» `(m, y)` требуется предсказать урожайность `Y_{m,y} ∈ R`. Прогноз строится по вектору признаков `x_{m,y}`, агрегирующему все модальности, накопленные графом знаний (L2, §2.1) к моменту прогноза за сезон `y` на поле `m`. В отличие от §2.2 (где единица анализа — ячейка `(s, t)` пространственно-временной сетки одного показателя), здесь единица анализа — пара «поле — сезон», а признаки — агрегаты по сезону.

Как показано в §1.3.5, ни один источник данных сам по себе не объясняет урожайность полностью: числовые показатели дают точечные измерения, дистанционное зондирование — интегральную характеристику полога, текст и фото — качественные события (поражения, обработки), которые в числовых рядах не отражены вовсе. Задача — построить единый вектор признаков, комплексирующий все модальности (научная новизна п. 2 введения), а не выбрать одну из них.

## 2.3.2. Таксономия модальностей и функции конструирования признаков

По аналогии с `μ = φ ∪ λ` из §2.1.4, для каждой модальности вводится функция агрегирования наблюдений графа знаний за сезон в вектор признаков фиксированной длины:

| Модальность | Источник (граф знаний, §2.1.3) | Функция признаков | Пример признаков |
|---|---|---|---|
| Числовая (`D_num`) | `ПоказательПочвы` от IoT-сенсоров и лабораторных анализов | `φ_num: {ПоказательПочвы}_{m,y} → R^{k_1}` | среднее/std влажности почвы за сезон, суммарные осадки, сумма эффективных температур |
| Спектральная/геопространственная (`D_geo`) | ДЗЗ-снимки, привязанные к `Поле` | `φ_geo: {снимки}_{m,y} → R^{k_2}` | пиковый NDVI, интеграл NDVI за сезон, дата пика |
| Изображения (`D_img`) | экземпляры `ВредительБолезнь`, связанные через фото (§2.1.4, расширение на изображения) | `φ_img: {ВредительБолезнь}_{m,y} → R^{k_3}` | число зафиксированных случаев поражения за сезон, максимальная `стадия_риска` |
| Текстовая, включая расшифрованные голосовые записи (`D_text`) | экземпляры `АгроПриём`, `ПогодноеСобытие`, извлечённые NER-конвейером из отчётов и ASR-транскриптов | `φ_text: {АгроПриём, …}_{m,y} → R^{k_4}` | число агроприёмов за сезон по типам (внесение удобрений, СЗР), суммарная доза |

Голосовые записи, как оговорено в §2.1.4, не требуют отдельной функции `φ_audio`: после ASR-транскрипции они становятся текстом и обрабатываются `φ_text` наравне с письменными источниками. Итоговый вектор признаков:

```
x_{m,y} = [ φ_num(m,y) ; φ_geo(m,y) ; φ_img(m,y) ; φ_text(m,y) ]  ∈ R^{k_1+k_2+k_3+k_4}
```

— конкатенация признаков всех модальностей. Такая конструкция прямо реализует **комплексирование гетерогенных признаков** (научная новизна п. 2 введения): модель работает не с «сырыми» модальностями по отдельности, а с их объединённым представлением, что и отличает предлагаемый подход от однмодальных моделей, раскритикованных в §1.3.5.

## 2.3.3. Ансамблевая прогнозная модель

Прогноз строится ансамблевым методом (Random Forest / Gradient Boosting, обоснование выбора — §1.3.1, устойчивость к разнородным по масштабу признакам без предварительной нормализации, способность улавливать нелинейные взаимодействия между модальностями):

```
Ŷ_{m,y} = F(x_{m,y}),   F ∈ {RandomForestRegressor, GradientBoostingRegressor}
```

Выбор конкретного алгоритма и гиперпараметров — предмет экспериментальной апробации (глава 4); формальная модель не привязана к конкретной реализации `F`, требуя лишь, чтобы `F` допускал последующее применение методов интерпретации (§2.3.4).

## 2.3.4. Интерпретация через SHAP

Для каждого прогноза `Ŷ_{m,y} = F(x_{m,y})` строится аддитивное разложение по признакам (значения Шепли, Lundberg & Lee, 2017):

```
Ŷ_{m,y} = φ_0 + Σ_j φ_j(m,y),   φ_0 = E[F(x)]
```

где `φ_j(m,y)` — вклад `j`-го признака в отклонение прогноза от базового уровня `φ_0`. Признаки группируются по модальности (таблица §2.3.2), и **агрегированный вклад модальности** определяется как:

```
Φ_k(m,y) = Σ_{j ∈ modality_k} |φ_j(m,y)|
```

Это даёт не просто точный прогноз, а количественный, интерпретируемый на языке предметной области ответ на вопрос «какая модальность (и какой конкретно фактор внутри неё) определила данный прогноз» — что и есть переход от «чёрного ящика» к объяснимой модели (научная новизна п. 2 введения, требование 4 из §1.4.2).

## 2.3.5. Схема валидации

Как показано в §1.2.2, агрономические данные пространственно и временн́о автокоррелированы. Случайное разбиение наблюдений `(m,y)` на обучающую и тестовую выборки нарушает предположение о независимости и завышает оценку качества (одно и то же поле в обучении и в тесте в разные годы делит один и тот же необъяснённый признак почвенного плодородия). Поэтому валидация проводится группированной кросс-валидацией **по полю** (`GroupKFold` с группой `m`): все сезоны данного поля целиком попадают либо в обучение, либо в тест, что проверяет способность модели обобщаться на **новые, не виденные поля**, а не просто на новые годы уже знакомых полей.

## 2.3.6. Критерии оценки качества

```
RMSE = sqrt( (1/N) Σ (Ŷ_{m,y} - Y_{m,y})² ),   R² = 1 - Σ(Ŷ-Y)² / Σ(Y-Ȳ)²
```

Критерий, аналогичный §2.2.6 для L3: мультимодальная модель не должна уступать по RMSE моделям, обученным на подмножестве модальностей (проверяется в `tests/test_prediction.py::test_multimodal_beats_single_modality` на контролируемых данных с известной функцией формирования урожайности, зависящей от всех четырёх модальностей).

## 2.3.7. Связь с реализацией

Реализовано в `src/ds_prediction/`: `features.py` (§2.3.2, функции `φ_num/φ_geo/φ_img/φ_text`), `synthetic.py` (контролируемый многолетний многополевой набор с известной функцией урожайности — по тем же причинам, что и в §2.2.7: нужен эталон для проверки ошибки), `model.py` (ансамбль + `GroupKFold` по полю, §2.3.3, §2.3.5), `explain.py` (обёртка над библиотекой `shap`, агрегация по модальностям, §2.3.4).

## Выводы

Раздел 2.3 формализует переход от отдельных модальностей (включая фото и голосовые заметки, сведённые к тексту через ASR) к единому вектору признаков, ансамблевому прогнозу и его SHAP-разложению по модальностям, с валидацией, учитывающей пространственную неоднородность полей (`GroupKFold`). Это реализует научную новизну п. 2 введения — переход от «чёрного ящика» к интерпретируемой мультимодальной модели.
