# Dataset Card: PlantDoc

## Источник и мотивация
Singh D., Jain N., Jain P., Kayal P., Kumawat S., Batra N. «PlantDoc: A Dataset for Visual Plant Disease Detection», CoDS-COMAD 2020. Создан для решения проблемы нехватки реалистичных (не лабораторных) фотографий поражений растений для визуальной диагностики. Репозиторий: `github.com/pratikkayal/PlantDoc-Dataset` (классификация), `github.com/pratikkayal/PlantDoc-Object-Detection-Dataset` (детекция, bbox).

## Состав
2598 изображений, 13 видов растений, до 17 классов поражений. Изображения собраны из открытых интернет-источников (не лабораторные снимки, в отличие от PlantVillage) — примерно 300 человеко-часов ручной разметки.

## Сбор данных
Скрапинг интернет-изображений с последующей ручной разметкой авторами публикации. Смещение выборки: то, что попадает в открытый интернет-поиск, не обязательно репрезентативно для всех регионов/сортов.

## Предобработка
В проекте не используется напрямую (сами изображения не загружены в этот репозиторий) — это внешний источник для будущей продовой версии `training/finetune_leaf_classifier.py --data-dir`, в формате `torchvision.datasets.ImageFolder`.

## Использование в проекте
Задокументирован как реальное («не синтетическое») ядро датасета для дообучения классификатора поражений (L1, `docs/chapter2/model_training.md`, §2.5.4). Фактическая загрузка и дообучение на нём — не выполнены в этой сессии (нет доступа к интернету из песочницы для скачивания изображений).

## Известные ограничения
Небольшой объём (2598 изображений) — авторы публикации сами отмечают это как основной недостаток относительно лабораторных датасетов вроде PlantVillage. Требует дополнения синтетическими или дополнительными реальными данными для достижения объёма, достаточного для продовой модели (см. `docs/governance/licenses.md`, раздел «Стратегия масштабирования»).
