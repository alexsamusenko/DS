# Открытые источники данных для наполнения и апробации

Апробация ведётся только на открытых данных (см. решение по опросу от 2026-07-30). Ниже — источники, сгруппированные по тому, какой уровень архитектуры (`docs/chapter2/ontology_model.md`, артефакт «Архитектура DS») они наполняют.

## Текстовые источники (наполнение L1 NLP-конвейера)

Здесь — открытый пробел, зафиксированный уже в главе 1 (§1.2.1): готового русскоязычного агрономического корпуса с NER-разметкой не существует. План:

1. Ручной сбор небольшого корпуса из **публично доступных** региональных рекомендаций Минсельхоза/НИИ и открытых агрономических статей (cyberleninka.ru и подобные) — точечно, не массовым скрапингом.
2. Разметка минимального набора сущностей (культура, агроприём, показатель, вредитель/болезнь) вручную поверх этого корпуса — на первом этапе достаточно 100–200 предложений для обкатки пайплайна.
3. В качестве базовой модели для NER — открытые предобученные модели для русского языка ([DeepPavlov](https://deeppavlov.ai/), RuBERT), дообучаемые на собранном мини-корпусе, а не обучаемые с нуля.

Этот пункт — самое узкое место реализации L1/L2 с текстовой стороны и требует отдельного решения, прежде чем NER-конвейер станет реалистичным (не блокирует формализацию онтологии и работу с числовыми/геоданными).

## Как это соотносится с задачей 6 диссертации

Открытые источники обеспечивают **формальную обкатку** модели (задачи 2–5): показать, что онтология строится и населяется, комбинированный алгоритм восстанавливает пропуски, модель прогнозирует и объясняет, оптимизатор считает дозы. Финальная апробация на данных конкретного хозяйства (глава 4, задача 6) остаётся отдельным шагом и потребует either доступа к реальному хозяйству, либо явного указания в тексте диссертации, что апробация проведена на открытых данных с оговоркой о репрезентативности.
