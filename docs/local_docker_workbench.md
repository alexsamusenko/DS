# Локальный запуск DS с хранилищем документов

## Требования

Docker Engine с Compose v2 (Docker Desktop на Windows/macOS или Docker Engine на Linux). Для OCR русского и английского текста в контейнер добавлены Tesseract и языковые пакеты. Сборка требует подключения к реестрам Docker, PyPI и npm.

## Запуск

```bash
git clone https://github.com/alexsamusenko/DS.git
cd DS
git checkout feature/end-to-end-pipeline
docker compose up --build -d app
docker compose ps
docker compose logs -f app
```

Веб-интерфейс: **http://localhost:8000**. Документация API: **http://localhost:8000/docs**. Healthcheck: **http://localhost:8000/health**. Перейдите во вкладку **«Центр решений АПК»**.

Сервис `app` содержит React, FastAPI, существующие пять модулей, Tesseract OCR, pypdf и парсеры XLSX/DOCX. Дополнительный `npm run dev` не нужен.

## Данные и сохранность

`docker-compose.yml` монтирует именованный том `ds_workbench` в `/app/workbench_data`. Он содержит исходные файлы с рандомизированными именами и каталог `catalog.sqlite3`. **Перезапуск и пересборка контейнера не удаляют том.** Команда `docker compose down -v` удалит том и данные, поэтому не используйте её для обычной остановки.

```bash
docker compose stop app
docker compose start app
docker compose down           # без -v, данные сохраняются
docker compose run --rm test
```

API:

- `POST /workbench/files` — загрузить один файл multipart/form-data.
- `GET /workbench/files` — список до 500 последних файлов.
- `GET /workbench/files/{file_id}` — метаданные, результат извлечения.
- `GET /workbench/files/{file_id}/download` — исходный файл.
- `POST /pipeline/runs` — отдельно запускаемый расчёт по структурированному JSON.

## Тестовый сценарий

1. Загрузите CSV и проверьте заголовки и строки.
2. Загрузите XLSX с несколькими листами и посмотрите предпросмотр ячеек.
3. Загрузите DOCX и PDF с печатным текстом и проверьте извлечённый текст.
4. Загрузите фото печатного журнала и фото рукописи: Tesseract попробует распознать текст; рукописный текст может распознаваться плохо.
5. Перезагрузите страницу и перезапустите `app`: файлы должны остаться в списке.
6. Скачайте оригинал, сравните SHA-256.
7. Запустите синтетический JSON-сценарий и убедитесь, что непроверенные данные не превращаются в производственные рекомендации.

## Ограничения MVP

Это локальный прототип. Не следует загружать конфиденциальные документы в экземпляр, доступный из интернета: пока нет полноценной изоляции пользователей, антивирусного сканирования, квот на общий объём, фоновой очереди OCR и защищённого документооборота. XLS/XLSM, ODS, HEIC, ZIP, GIS и многие прочие форматы могут быть сохранены, но не все разобраны. XLSX/DOCX поддерживают ограниченный предварительный просмотр. PDF извлекает текстовый слой, а сканы PDF требуют отдельного OCR-конвейера. Распознанные значения ещё не преобразуются автоматически в проверенные показатели DS.

Все результаты извлечения имеют статус `registered_untrusted` и `pipeline_ready=false`. Их необходимо проверять и связывать с полями, датами и единицами измерения до использования в расчётах.
